# RGVNet

Code and experiment configurations for agricultural parcel delineation with DRR and CEV.

## Getting the code and initialization weights

Install Git LFS, then clone the repository and fetch the initialization checkpoints:

```bash
git lfs install
git clone https://github.com/wykk0521/RGVNet.git
cd RGVNet
git lfs pull
```

The checkpoints are Git LFS files. Downloading only a source ZIP may leave pointer files instead of the weights; the commands above retrieve the actual files.

## Environment

The experiments used Python 3.11.15 and PyTorch 2.0.1 with CUDA 11.8 on NVIDIA A40 GPUs.
`requirement.txt` pins the 39 Python distributions resolved in the working training environment, including their active dependencies.
Python and the NVIDIA driver are installed separately.

```bash
conda create -n rgvnet python=3.11
conda activate rgvnet
python -m pip install -r requirement.txt
```

## Contents

- `models/`: the complete RGVNet, HBGNet and DRR-only implementations and dataset/seed-specific configurations.
- `tools/`: DRR, CEV, CEV's shared v8 implementation, and boundary-band losses.
- `ai4boundaries/` and `fhapd/`: dataset preparation and evaluation code.
- `splits/`: the nine train/validation/test image-ID lists, without imagery or labels.
- `revision/code/`: five-seed experiments, single-window and matched-supervision ablations, SegFix, candidate selection, stitching and latency analysis.
- `revision/jobs/`: source/configuration contracts and trainers; no completed-run outputs.
- `revision/third_party/openseg/`: the SegFix implementation and its original license.
- `pretrained/`: PVT-v2-B2 and HRNet-W48 backbone initialization checkpoints, with checksums and the available provenance records.

## Data and outputs

The default dataset roots remain under `/root/wyk5/dataset` on the current server. The code root has been relocated to `/root/wyk5/RGVNet`; the original project and all its results are preserved.
The included manifests contain image IDs only. Dataset images, reference masks, trained model checkpoints, logs and prediction figures are external inputs or newly generated outputs, not files in this collection.

Model packages retain the original training-time engineering checks. Run their supplied verification scripts before starting a new training run; historical verification-pass receipts are not included. The revision trainers additionally check their shipped source/configuration contracts and dataset hashes.
Formal-test, timing and aggregation scripts require the checkpoints and evaluation outputs generated by the corresponding runs. Backbone initialization weights are not trained RGVNet checkpoints.

## Initialization weights

The initialization checkpoints are indexed in `pretrained/`. Model-package and SegFix paths use hard links to share the same underlying files on this server. Use a hard-link-preserving copy such as `rsync -aH` to retain this disk-space saving; an ordinary copy remains usable but duplicates the file data.
`pretrained/pvt_v2_b2.json` retains the original record of the user-supplied initialization file; `revision/third_party/provenance.json` retains the SegFix source/download provenance. Checksums are listed in `pretrained/checksums.json`.
`.gitattributes` tracks all initialization checkpoint paths with Git LFS.

The third-party source notices and available licenses are preserved. This collection does not assign a new blanket license to upstream code.
